# UI5 Seed Application

A project template for UI5 applications. You can copy this template and use it for your own UI5 projects.  

:warning: The grunt-based UI5 Seed Application is deprecated. You can find the latest commit here: [Link to Gitea](https://gitea.wgn.wuerth.com/UI5/ui5-seed-application/src/commit/fb903af9352796171c16cfd845ad00c622f97aa9)

## Getting started

1. Prepare/check your [development environment](https://gitea.wgn.wuerth.com/UI5/ui5-wui-common-docs/src/docs/local-dev-environment.md).

2. Optional: [proxy configuration](https://gitea.wgn.wuerth.com/UI5/ui5-wui-common-docs/src/docs/proxy-settings.md) in case you are working behind a proxy.

3. Clone the repository and navigate into it:

    ```sh
    # https would work, but ssh is preferred
    # git clone https://gitea.wgn.wuerth.com/UI5/ui5-seed-application.git
    git clone ssh://git@gitea.wgn.wuerth.com:29420/UI5/ui5-seed-application.git
    # switch into created directory
    cd ui5-seed-application
    ```

4. Install all npm dependencies: `npm install`.

5. Run the project with `npm run start`. Please check
   [the documentation](https://gitea.wgn.wuerth.com/UI5/ui5-wui-common-docs/src/docs/npm-scripts.md) about available npm scripts for
   testing and building.

6. Preparing a version for deployment - please check
   [the versioning documentation](https://gitea.wgn.wuerth.com/UI5/ui5-wui-common-docs/src/docs/versioning.md).

7. Deployment - please check [the deployment documentation](https://gitea.wgn.wuerth.com/UI5/ui5-wui-common-docs/src/docs/deployment.md).

8. In case of problems please first check [hints and troubleshooting](https://gitea.wgn.wuerth.com/UI5/ui5-wui-common-docs/src/docs/hints.md) document.
